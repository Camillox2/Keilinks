# Manifestos de dados V4

Os arquivos JSON desta pasta são gerados localmente por `python -m treino.v4.preparar_dados download` e registram origem, configuração, licença declarada, data, quantidade de registros, bytes, rejeições e duplicatas.

Antes de redistribuir ou usar comercialmente qualquer corpus, confira o card atual de cada dataset e os termos dos conteúdos de origem. Dados grandes, binários tokenizados e checkpoints não devem ser commitados no Git.
