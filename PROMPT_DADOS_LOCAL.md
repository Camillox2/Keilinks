# Prompt para preparar os dados localmente

O prompt completo para o agente local está na descrição do PR da Keilinks V4 e pode ser atualizado conforme o hardware, espaço livre e fontes disponíveis.

Ele deve executar o pipeline em estágios, validar licenças e amostras, nunca enviar corpora grandes ao Git e parar antes do treino longo, deixando os comandos finais prontos.
